# Tutorials

If you are new to JSAR and want to learn how to use it quickly, you can follow the tutorials below.

## Hello World

Get started with your first JSAR application using popular 3D frameworks:

### Hello World with Three.js
Learn how to create a basic 3D scene using Three.js in the JSAR environment, including setting up the camera, lighting, and basic geometry.

### Hello World with Babylon.js
Create your first spatial application using Babylon.js, exploring the engine's features for XR development.

## Space Development Samples

Explore more advanced spatial computing concepts:

### Creating Spatial Images
Learn how to display and manipulate images in 3D space, including positioning, scaling, and interactive behaviors.

### 3D Text and Typography
Understand how to render text in spatial environments, including font loading, styling, and layout considerations.

## Networking

Connect your spatial applications to the web:

### Send HTTPS Request
Learn how to make HTTP requests from your JSAR applications to fetch data from web services and APIs.

### WebSocket Client
Implement real-time communication using WebSockets, perfect for multiplayer experiences or live data streaming.

## Advanced Topics

### Performance Optimization
Best practices for maintaining smooth frame rates in spatial applications.

### Asset Management
Efficient loading and caching strategies for 3D models, textures, and other assets.

### User Interaction
Implementing intuitive input handling for hand tracking, eye gaze, and voice commands.
