# Basic Concepts

In this chapter, we will introduce some fundamental concepts of JSAR or XR development, these concepts are essential to understand how JSAR objectives will be achieved. And also, they are important for Web developers to learn about Web development in XR.

## Spaces

Learn about the spatial computing environment and how JSAR handles 3D spaces, coordinate systems, and spatial relationships in XR applications.

## Input System

Understand how JSAR processes various input sources including hand tracking, eye tracking, voice commands, and traditional input devices in spatial computing environments.

## Recap of HTML

Review how familiar HTML concepts translate to spatial web development and what new possibilities emerge when HTML elements can exist in 3D space.
