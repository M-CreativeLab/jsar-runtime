# Runtime

During runtime, JSAR relies primarily on Node.js, Babylon.js, and its own implementation of web-standard APIs:

Below are the version details of the dependencies for JSAR runtime:

| Dependency | Version |
| --- | --- |
| Node.js | v18.12.1 |
| Babylon.js | v6.10.0 |

> The above information will be updated with each JSAR version release.

## Runtime Components

### Babylon.js APIs
JSAR integrates with Babylon.js to provide powerful 3D rendering capabilities, allowing developers to create immersive spatial experiences using familiar web technologies.

### Web-standard APIs
Implementation of standard web APIs adapted for spatial computing environments, ensuring compatibility with existing web development knowledge.

### Node.js APIs
Server-side JavaScript runtime capabilities that enable backend functionality within JSAR applications.

### JSAR APIs
Custom APIs specifically designed for spatial web development, providing unique features for XR environments.

### Resource Cache
Efficient caching system for spatial assets, ensuring optimal performance in XR applications.

### Module System
Modern ES6+ module system with TypeScript support, enabling modular application development.
