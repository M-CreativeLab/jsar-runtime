XSML

XSML is a markup language very similar to HTML. Its full name is eXtensible Spatial Markup Language, and it extends HTML by reusing some of its tags, such as head, title, script, style, div, and introduces additional tags for spatial representation, such as replacing body with space and using cube to represent a cube, among others.

<h4>link</h4>
<p>The </code><link><code> tag is used to define the link information in XSML. It has attributes like:</p>
<li></code>id<code>: Represents the unique identifier of the link, and its value is a string.</li>
<li></code>rel<code>: Indicates the relationship of the link, and its value is a string. Currently, only </code>mesh<code> is supported.</li>
<li></code>type<code>: Specifies the type of the link, and its value is a string. Currently, only </code>octstream/glb<code> is supported.</li>
<p>In HTML, the </code><link><code> tag is typically used to reference CSS files. However, in XSML, the </code><link><code> tag is used to reference 3D model files, such as </code>glb<code> format 3D model files.</p>
<p>In future versions, we will also support using this tag to import SCSS and other model file formats. The specific support is as follows:</p>
<p>| </code>rel<code> | Description | Supported | | --- | --- | --- | | </code>mesh<code> | The 3D model used in the current document | Yes | | </code>alternate<code> | Alternate document for the current document | No | | </code>author<code> | Author of the current document | No | | </code>bookmark<code> | Bookmark for the current document | No | | </code>canonical<code> | Canonical address of the current document | No | | </code>dns-prefetch<code> | DNS prefetch for the current document | No | | </code>help<code> | Help for the current document | No | | </code>icon<code> | Icon for the current document | No | | </code>license<code> | License for the current document | No | | </code>manifest<code> | Manifest for the current document | No | | </code>modulepreload<code> | Module preload for the current document | No | | </code>next<code> | Next document for the current document | No | | </code>pingback<code> | PingBack for the current document | No | | </code>preconnect<code> | Preconnect for the current document | No | | </code>prefetch<code> | Prefetch for the current document | No | | </code>preload<code> | Preload for the current document | No | | </code>prerender<code> | Prerender for the current document | No | | </code>prev<code> | Previous document for the current document | No | | </code>search<code> | Search for the current document | No | | </code>stylesheet<code> | Stylesheet for the current document | No | | </code>tag<code> | Tag for the current document | No |</p>
<h4>script</h4>
<p>The </code><script><code> tag is used to define script information in XSML, and it has the following attribute:</p>
<li></code>src<code>: Represents the URL of the script, and its value is a string.</li>
<p>In XSML, the </code><script><code> tag can be used to import both JavaScript and TypeScript files. If you are importing a TypeScript file, you can specify the file extension as </code>.ts<code> in the </code>src<code> attribute. Importing TypeScript scripts does not require additional code compilation.</p>
<p>In the current version, XSML does not yet support CommonJS or ECMAScript Module systems. However, you can achieve cross-file referencing by attaching the global variable </code>global.spaceDocument<code>. This approach is not recommended as it can decrease code readability.</p>
<p>We plan to add support for ECMAScript Modules in JSAR in the future.</p>
<h4>style</h4>
<p>The </code><style><code> tag is used to define style information in XSML. It serves a similar purpose to the </code>style<code> tag in HTML and has the following attribute:</p>
<li></code>type<code>: Specifies the style's type, and its value is a string. Currently, only </code>text/scss<code> is supported.</li>
<p>Here's an example of a </code><style><code> tag in XSML:</p>
<p></code></pre>xml <xsml version="1.0">   <head>     <style type="text/scss">       @material yellow {         diffuse-color: #fdd276;         backface-culling: false;         side-orientation: frontside;       }       #lion {         rotation: 0 0 0;       }       #lion_body {         material: "yellow";         position: 0 -30 -60;       }       #lion_head {         y: 60;         z: -50;       }       #lion_face {         material: "yellow";         position: 0 0 135;       }       #lion_mane {         position: 0 -10 80;       }     </style>   </head>   <space>     <!-- Spatial structure -->   </space> </xsml> <pre><code class="language-"> You can see that by using the </code><style><code> tag's content, you can define styles just like CSS. You can find elements using CSS selectors and apply styles to those selected elements. The difference is that you're now defining 3D styles instead of flat styles.</p>
<p>For example, we use the syntax of </code>@font-family<code> and </code>@keyframes<code> to define materials in 3D. In the </code><material><code> tag, you can set material types, colors, textures, and more. Then, in specific elements, you can use the </code>material<code> attribute to apply the corresponding material definition.</p>
<p>Similarly, we have extended the original style definitions by adding properties like </code>position<code>, </code>rotation<code>, </code>scale<code>, etc., to define the position, rotation, and scale of 3D elements.</p>
<p>> Note: The current version only supports querying by id, and later versions will also support CSS queries by element tag and class.</p>
<p>> For more information about the </code><style><code> tag, you can refer to <a href="./basic-concepts/intro-scss">SCSS</a>.</p>
<h3>space</h3>
<p>The </code><space><code> tag is used to define the spatial structure of XSML. Its child tags include </code>mesh<code>, </code>cube<code>, </code>sphere<code>, </code>cylinder<code>, </code>cone<code>, </code>plane<code>, </code>text<code>, </code>image<code>, </code>video<code>, </code>audio<code>, etc.</p>
<h4>mesh</h4>
<p>The </code><mesh><code> tag is used to define XSML mesh elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the mesh element, with its value being a string.</li>
<li></code>ref<code>: Represents the reference of the mesh element, with its value as a string, currently only supporting </code>model<code>.</li>
<li></code>selector<code>: Represents the selector of the mesh element, with its value being a string.</li>
<p>This tag is used to render 3D model files imported via the </code><link><code> tags in the </code><head><code> tag into the space. The </code>ref<code> attribute specifies the id of the imported 3D model file, and the </code>selector<code> attribute specifies the node of the imported 3D model file.</p>
<h4>cube</h4>
<p>The </code><cube><code> tag is used to define XSML cube elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the cube element, with its value being a string.</li>
<li></code>width<code>: Represents the width of the cube element, with its value being a number.</li>
<li></code>height<code>: Represents the height of the cube element, with its value being a number.</li>
<li></code>depth<code>: Represents the depth of the cube element, with its value being a number.</li>
<li></code>size<code>: Represents the size of the cube element, with its value being a number.</li>
<p>This tag is used to define a cube element, with the </code>width<code>, </code>height<code>, and </code>depth<code> attributes specifying the width, height, and depth of the cube element.</p>
<h4>plane</h4>
<p>The </code><plane><code> tag is used to define XSML plane elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the plane element, with its value being a string.</li>
<li></code>width<code>: Represents the width of the plane element, with its value being a number.</li>
<li></code>height<code>: Represents the height of the plane element, with its value being a number.</li>
<li></code>size<code>: Represents the size of the plane element, with its value being a number.</li>
<p>This tag is used to define a plane element, with the </code>width<code> and </code>height<code> attributes specifying the width and height of the plane element.</p>
<h4>sphere</h4>
<p>The </code><sphere><code> tag is used to define XSML sphere elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the sphere element, with its value being a string.</li>
<li></code>segments<code>: Represents the number of segments of the sphere element, with its value being a number.</li>
<li></code>diameter<code>: Represents the diameter of the sphere element, with its value being a number.</li>
<li></code>diameterX<code>: Represents the X-axis diameter of the sphere element, with its value being a number.</li>
<li></code>diameterY<code>: Represents the Y-axis diameter of the sphere element, with its value being a number.</li>
<li></code>diameterZ<code>: Represents the Z-axis diameter of the sphere element, with its value being a number.</li>
<li></code>arc<code>: Represents the arc of the sphere element, with its value being a number.</li>
<li></code>slice<code>: Represents the number of slices of the sphere element, with its value being a number.</li>
<p>This tag is used to define a sphere element, with the </code>segments<code> attribute specifying the number of segments, and the </code>diameter<code>, </code>diameterX<code>, </code>diameterY<code>, </code>diameterZ<code>, </code>arc<code>, and </code>slice<code> attributes specifying the diameter, dimensions, arc, and slices of the sphere element.</p>
<h4>cylinder</h4>
<p>The </code><cylinder><code> tag is used to define XSML cylinder elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the cylinder element, with its value being a string.</li>
<li></code>height<code>: Represents the height of the cylinder element, with its value being a number.</li>
<li></code>diameter<code>: Represents the diameter of the cylinder element, with its value being a number.</li>
<li></code>diameterTop<code>: Represents the top diameter of the cylinder element, with its value being a number.</li>
<li></code>diameterBottom<code>: Represents the bottom diameter of the cylinder element, with its value being a number.</li>
<li></code>tessellation<code>: Represents the number of tessellations of the cylinder element, with its value being a number.</li>
<p>This tag is used to define a cylinder element, with the </code>height<code> attribute specifying the height, and the </code>diameter<code>, </code>diameterTop<code>, </code>diameterBottom<code>, and </code>tessellation<code> attributes specifying the diameters and tessellations of the cylinder element.</p>
<h4>capsule</h4>
<p>The </code><capsule><code> tag is used to define XSML capsule elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the capsule element, with its value being a string.</li>
<li></code>height<code>: Represents the height of the capsule element, with its value being a number.</li>
<li></code>radius<code>: Represents the radius of the capsule element, with its value being a number.</li>
<li></code>radiusTop<code>: Represents the top radius of the capsule element, with its value being a number.</li>
<li></code>radiusBottom<code>: Represents the bottom radius of the capsule element, with its value being a number.</li>
<p>This tag is used to define a capsule element, with the </code>height<code> attribute specifying the height, and the </code>radius<code>, </code>radiusTop<code>, and </code>radiusBottom<code> attributes specifying the radii of the capsule element.</p>
<h4>torus</h4>
<p>The </code><torus><code> tag is used to define XSML torus elements. It has the following attributes:</p>
<li></code>id<code>: Represents the unique identifier of the torus element, with its value being a string.</li>
<li></code>diameter<code>: Represents the diameter of the torus element, with its value being a number.</li>
<li></code>thickness<code>: Represents the thickness of the torus element, with its value being a number.</li>
<li></code>tessellation<code>: Represents the number of tessellations of the torus element, with its value being a number.</li>
<h4>bound</h4>
<p>The </code><bound><code> tag is used to define XSML bounding box elements. It represents the bounding box of its parent element, and its attributes include:</p>
<li></code>id<code>: Represents the unique identifier of the bounding box element, with its value being a string.</li>
<p>This tag is used to define a bounding box element, and its size is calculated based on its child elements. Internally, it is a Babylon.js TransformNode object.</p>
