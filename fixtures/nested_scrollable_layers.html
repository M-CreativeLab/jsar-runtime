Nested Scrollable Container Test Fixture

This fixture demonstrates the layered rendering requirements:

  • Layer 0 (Outer Container): Fixed 400x300 viewport with overflow:hidden
  • Layer 1 (Scrollable Container): 200x150 scrollable area with overflow:auto
  • Layer 2 (Inner Content): 180x100 content area with overflow:hidden

Expected rendering order: Layer 0 → Layer 1 → Layer 2 (painter's order)

Clipping hierarchy: Each layer clips its children to its bounds

Layer Rendering Validation

For correct layered rendering, the system should:

  1. Render Layer 0 background first
  2. Apply Layer 0 clipping (400x300 bounds)
  3. Render Layer 1 with scroll transform
  4. Apply Layer 1 clipping (200x150 bounds)
  5. Render Layer 2 content
  6. Apply Layer 2 clipping (180x100 bounds)
  7. Pop clipping states in reverse order
