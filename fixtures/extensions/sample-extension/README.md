# Sample Extension

This is a sample extension for JSAR runtime that demonstrates basic extension functionality.

## Features

- Basic manifest.json structure
- Background script execution
- Extension API access
- Console logging for debugging

## Files

- `manifest.json` - Extension metadata and configuration
- `background.js` - Background script that runs when extension is loaded
- `README.md` - This documentation file

## Usage

This extension is automatically loaded when placed in the extensions directory and demonstrates:

1. Extension loading and initialization
2. Background script execution
3. Basic extension API access
4. Event handling setup

The extension will log information to the console when loaded, indicating successful initialization.
