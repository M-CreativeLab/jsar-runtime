Test Results

Each box above should show a red square with a white circle containing an "X" positioned according to the specified background-position value. The background image is 40x40 pixels.

Expected Behavior:

  • 1-value: Keywords position on one axis, center on the other. Length/percentage positions horizontally, centers vertically.
  • 2-value: First value is horizontal, second is vertical.
  • 3-value: One keyword with offset, one keyword without offset.
  • 4-value: Two keywords, each with their respective offsets.
