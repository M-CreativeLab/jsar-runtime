CSS white-space Edge Cases Test

Test 1: Multiple consecutive spaces

Expected (normal): "hello world"
hello world
Expected (pre): "hello world"
hello world

Test 2: Newlines and spaces

Expected (normal): "hello world"
hello world
Expected (pre-line): "hello\nworld" (preserves newline)
hello world

Test 3: Leading/trailing whitespace

Expected (normal): "content" (trimmed)
content
Expected (pre): " content " (preserved)
content

Test 4: Empty content with spaces

Expected (normal): "" (empty)
Expected (pre): " " (preserved)

Test 5: Tabs and spaces mixed

Expected (normal): "hello world" (collapsed)
hello world
Expected (pre): "hello world" (preserved)
hello world

Test 6: Complex whitespace patterns

Expected (normal): "line1 line2 line3"
line1 line2 line3
Expected (pre-line): "line1\n\nline2\nline3" (preserves newlines)
line1 line2 line3
