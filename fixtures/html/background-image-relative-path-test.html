Background Image Relative Path Test

Test Purpose: Verify that background-image supports relative paths and resolves them correctly based on the document's base URI.
  • Relative paths like ./test-image.png should be resolved relative to the current document
  • Parent directory paths like ../images/test-image.png should navigate up one level
  • Subdirectory paths like images/test-image.png should look in subdirectories
  • Absolute URLs and data URLs should remain unchanged

Test 1: Same Directory

CSS: background-image: url('./test-image.png');

Expected: Image should be resolved relative to the current document location

Test 2: Parent Directory

CSS: background-image: url('../images/test-image.png');

Expected: Image should be resolved one level up from the current document

Test 3: Subdirectory

CSS: background-image: url('images/test-image.png');

Expected: Image should be resolved in the images subdirectory

Test 4: Absolute URL

CSS: background-image: url('https://example.com/test-image.png');

Expected: URL should remain unchanged (absolute URL)

Test 5: Data URL

CSS: background-image: url('data:image/svg+xml,<svg...>');

Expected: Red square should appear (data URL)
