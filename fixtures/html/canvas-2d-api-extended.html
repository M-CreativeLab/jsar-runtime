Canvas 2D API Extended Features Demo

This demo showcases the new Canvas 2D API methods and properties added to JSAR Runtime, including strokeRect, strokeText, ellipse, rect, line dash properties, shadow effects, resetTransform, and clipping.

New Drawing Methods

Demonstrating strokeRect() and strokeText() methods

New Path Methods

Demonstrating ellipse() and rect() methods

Line Properties

Demonstrating getLineDash(), setLineDash(), lineDashOffset, and miterLimit

Shadow Effects

Demonstrating shadowBlur, shadowColor, shadowOffsetX, and shadowOffsetY

Transform and Clipping

Demonstrating resetTransform() and clip() methods
