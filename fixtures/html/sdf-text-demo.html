SDF Text Rendering - Integrated

Enhanced WebContent texture pipeline with SDF anti-aliasing

This demonstration showcases the integrated SDF text rendering approach in the JSAR runtime. Instead of a separate SDF system, SDF anti-aliasing is integrated into the existing RenderTextSystem and WebContentInstancedMaterial pipeline.

Integrated SDF approach benefits:
• Uses existing Text2d components
• Works through WebContent instance textures
• No separate rendering system needed
• Extends to SVG images and other content
• Backward compatible - no impact when disabled
• Unicode character support: 你好世界 🌍 ñáméş
To enable integrated SDF text rendering:
Set the environment variable JSAR_ENABLE_SDF_TEXT=1 before running the application.

Integration details:
• RenderTextSystem::render() detects SDF mode automatically • WebContentInstancedMaterial enables SDF anti-aliasing • Same texture atlas and batching as other content • Generic infrastructure for future SDF content types
