SDF Text Rendering

Crisp, scalable text in 3D space

This demonstration showcases SDF (Signed Distance Field) based text rendering in the JSAR runtime. SDF text remains crisp and clean at any scale or distance, making it ideal for spatial computing and 3D user interfaces.

SDF text supports various features:
• Smooth edges at any scale
• Efficient GPU rendering
• Configurable thickness and softness
• Font family and style support
• Unicode character support: 你好世界 🌍 ñáméş
To enable SDF text rendering:
Set the environment variable JSAR_ENABLE_SDF_TEXT=1 before running the application.

Performance benefits:
• No pixelation when scaling text • Reduced texture memory usage • Batched rendering for multiple text elements • LRU cache prevents redundant SDF generation
