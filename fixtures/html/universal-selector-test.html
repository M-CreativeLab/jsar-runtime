Universal Selector (*) Test Cases

This page tests the universal selector (*) implementation in various contexts and combinations.

1. Basic Universal Selector

CSS: .basic-test * { border: 2px solid red; margin: 2px; padding: 5px; }

This paragraph should have a red border.

This div should have a red border.
This span should have a red border.

2. Compound Selectors with Universal

CSS: *.highlight, *#special, *.highlight#combo

Universal + class selector (*.highlight) - should be yellow

Universal + ID selector (*#special) - should be light blue
Universal + class + ID (*.highlight#combo) - should be green

Regular paragraph - no special styling

3. Combinators with Universal

CSS: .parent *, .direct-parent > *, h3 + *, h4 ~ *

Descendant of .parent (should be light red)

Nested descendant (should be light red)

Direct child of .direct-parent (should be light green)

Not a direct child (no green background)

Adjacent Sibling Test

Element immediately following h3 (should be light blue and italic)

Second element after h3 (no special styling)

General Sibling Test

First element after h4 (should be light yellow and underlined)

Second element after h4 (should be light yellow and underlined)
Third element after h4 (should be light yellow and underlined)

4. Pseudo-classes with Universal

CSS: *:hover, *:focus, *:first-child, *:last-child

First child (should have green left border)

Last child (should have red right border)

5. Complex Selectors

CSS: div * + span, .container > *:nth-child(even), .nested * *

First child (odd)

Second child (even - should be gray)
Third child (odd)
Fourth child (even - should be gray)

Paragraph

Span after paragraph (should be pink and bold)
Deeply nested element (should have dotted border)

Another deeply nested element (should have dotted border)

Universal selector - should be red

Class selector wins over universal - should be blue

ID with universal wins - should be green
