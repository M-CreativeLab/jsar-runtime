CSS Overflow Comprehensive Test

This page tests various CSS overflow properties and scenarios.

overflow: visible
This content is longer than the container and will overflow outside the boundaries. The overflow: visible property allows content to extend beyond the container's edges, which is the default behavior.
overflow: hidden
This content is longer than the container but will be clipped and hidden. The overflow: hidden property cuts off any content that extends beyond the container's boundaries without providing scrollbars.
overflow: scroll
This content is longer than the container and will show scrollbars. The overflow: scroll property always shows scrollbars, even if the content fits within the container boundaries.
overflow: auto
This content is longer than the container and will show scrollbars only when needed. The overflow: auto property dynamically shows or hides scrollbars based on whether content overflows.
overflow-x: hidden, overflow-y: scroll
This content has horizontal overflow hidden but vertical scrolling enabled. This is useful for preventing horizontal scrolling while allowing vertical navigation through content.
overflow-x: scroll, overflow-y: hidden
This content has vertical overflow hidden but horizontal scrolling enabled. This creates a horizontally scrollable area while preventing vertical overflow from being accessible.
