Expected Behavior:

  • translateX(50%): Should move element right by 50% of its width (50px for 100px wide element)
  • translateY(50%): Should move element down by 50% of its height (40px for 80px high element)
  • translate3d(0, 50%, 0): Same as translateY(50%)
  • translate(50%, 50%): Should move by 50% width and 50% height
  • Centering: left: 50% + translateX(-50%) should center the element horizontally
  • Combined: Percentage should work with other transforms
  • Negative: translate(-25%, -25%) should move element up and left
  • Large percent: translateX(100%) should move element by its full width
