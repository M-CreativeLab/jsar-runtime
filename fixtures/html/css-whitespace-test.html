CSS white-space Property Demonstration

Basic white-space Values

The following examples show how different white-space values handle the same text content:

Text content: "Hello world!\nThis is a test\n with multiple spaces."
white-space: normal
Hello world! This is a test with multiple spaces.
white-space: nowrap
Hello world! This is a test with multiple spaces.
white-space: pre
Hello world! This is a test with multiple spaces.
white-space: pre-line
Hello world! This is a test with multiple spaces.
white-space: pre-wrap
Hello world! This is a test with multiple spaces.
white-space: break-spaces
Hello world! This is a test with multiple spaces.

Tab Character Handling

How different white-space values handle tab characters:

white-space: normal
Text with tabs between words.
white-space: pre
Text with tabs between words.
white-space: pre-wrap
Text with tabs between words.

Line Breaking Behavior

Long text to demonstrate wrapping behavior:

white-space: normal
This is a very long line of text that should wrap naturally when it reaches the edge of the container because normal allows wrapping.
white-space: nowrap
This is a very long line of text that should not wrap and will overflow the container because nowrap prevents wrapping.
white-space: pre-wrap
This is a very long line of text that should wrap naturally when it reaches the edge of the container because pre-wrap allows wrapping while preserving spaces.

Leading and Trailing Spaces

How leading and trailing spaces are handled:

white-space: pre

white-space: pre-wrap

Mixed Content Example

Real-world example with code formatting:

white-space: pre (for code formatting)
function example() { if (condition) { console.log("Hello world!"); return true; } return false; }
white-space: normal (same content)
function example() { if (condition) { console.log("Hello world!"); return true; } return false; }
