Canvas 2D API Coverage

These test pages provide comprehensive coverage of the Canvas 2D API as implemented in JSAR Runtime:

  • Drawing methods: fillRect, strokeRect, clearRect, fill, stroke
  • Path methods: beginPath, closePath, moveTo, lineTo
  • Curve methods: bezierCurveTo, quadraticCurveTo, arc, arcTo, ellipse
  • Text methods: fillText, strokeText, measureText
  • Transform methods: translate, rotate, scale, transform, setTransform
  • Image methods: drawImage, createImageData, getImageData, putImageData
  • State methods: save, restore
  • Style properties: fillStyle, strokeStyle, lineWidth, lineCap, lineJoin
  • Text properties: font, textAlign, textBaseline
  • Global properties: globalAlpha, globalCompositeOperation
  • Line dash: setLineDash, getLineDash
  • Gradients: createLinearGradient, createRadialGradient
  • Patterns: createPattern
