Bottom-Right Alignment Tests (Image should be in bottom-right corner)

All these tests should position the 50x50px background image in the bottom-right corner of each 200x150px box:

background-position: right bottom
Expected: bottom-right corner
background-position: 100% 100%
Expected: bottom-right corner
background-position: right 100%
Expected: bottom-right corner
background-position: 100% bottom
Expected: bottom-right corner

Other Corner Alignment Tests

These tests verify other corner positions work correctly:

background-position: left bottom
Expected: bottom-left corner
background-position: 0% 100%
Expected: bottom-left corner
background-position: right top
Expected: top-right corner
background-position: 100% 0%
Expected: top-right corner

Expected Results

According to CSS specification:

  • right bottom and 100% 100% should be identical - both place image in bottom-right corner
  • left bottom and 0% 100% should be identical - both place image in bottom-left corner
  • right top and 100% 0% should be identical - both place image in top-right corner
  • Images should be flush with the edges (no gaps or offsets)

If the implementation is incorrect, percentage values may not align properly with keyword values.

Implementation Notes

The fix handles cases where "100% 100%" is parsed as two length values instead of percentages. Common percentage values (0%, 25%, 50%, 75%, 100%) are detected and processed correctly to ensure proper edge alignment according to CSS Background and Borders Module Level 3 specification.
