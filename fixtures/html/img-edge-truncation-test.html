图片边缘截断测试
Image Edge Truncation Test

测试目的 Test Purpose: 验证图片在容器边界处是否正确截断，检查是否出现边缘渲染问题
Expected Behavior: Images should be cleanly truncated at container boundaries without edge artifacts

基础溢出测试 - Basic Overflow Tests

Large image in small container (100x100px) - 大图片小容器
Expected: Image should be truncated at container edges. Red lines show center guides.
Large image in medium container (200x150px) - 大图片中等容器
Expected: Partial image visible, cleanly cut at borders without bleeding.
SVG image overflow test - SVG图片溢出测试
Expected: SVG should be truncated same as raster images.

对象适配测试 - Object-fit Tests

object-fit: cover
Should cover entire container, may be cropped
object-fit: contain
Should fit entirely within container
object-fit: fill
Should stretch to fill container
object-fit: scale-down
Should scale down if needed

定位图片测试 - Positioned Images Tests

Absolutely positioned image extending outside container - 绝对定位超出容器
Expected: Image positioned at top: -50px, left: -50px should be truncated at container boundaries.

圆角容器测试 - Rounded Containers Tests

border-radius: 10px
Image should follow rounded corners
border-radius: 50px (circular)
Image should be clipped to circular shape

边界情况测试 - Edge Cases Tests

Multiple images in same container - 同一容器多张图片
Expected: Both images should be clipped at container boundaries, overlapping areas should blend correctly.
Zero-sized container - 零尺寸容器
Expected: Nothing should be visible (image completely clipped).
Very small container (1x1px) - 极小容器
Expected: Only 1 pixel should be visible (scaled up 20x for visibility).

性能测试 - Performance Test

Multiple truncated images - 多个截断图片
Expected: Smooth rendering of multiple clipped images without performance degradation.
