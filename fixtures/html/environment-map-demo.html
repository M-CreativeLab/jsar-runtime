🎯 Environment Map Testing

This demo shows the environment map rendering in action.

How to Test:

  • Look Up: You should see a light blue sky background
  • Look Around: Horizon areas show warm orange/yellow colors
  • Look Down: Ground areas display brown earth tones
  • Move Your Head: Colors transition smoothly as you change orientation

Command Line Options:

# Enable environment map (default)
jsar_desktop_opengl --env-map

# Disable environment map  
jsar_desktop_opengl --no-env-map

# Stereo mode with environment map
jsar_desktop_opengl --stereo singlepass --env-map
